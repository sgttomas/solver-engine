  1. Structure & Layout
   * Agreement: Co-Developer-1 correctly interprets the "flat layout" rule. The

  2. Schema Parity & Source of Truth
   * Agreement: The migration file (001_initial_schema.py) is the physical

     when Doc 3 is ambiguous), the migration wins.
   * Critical Catch: "Only add FKs/constraints that exist in the migration."
     This is vital. The latest_artifact_id and artifact_id columns in
     step_executions and audit_log are logical references but not physical
     Foreign Keys in the schema (likely to allow loose coupling or avoid
     circular deletion issues). Adding a SQLAlchemy ForeignKey constraint where
     none exists in Postgres would cause Alembic to generate unwanted migrations
     or fail validation.

  3. Enum Handling
   * Agreement: create_type=False is non-negotiable since the types are already
     created by the raw SQL.
   * Refinement: Co-Developer-1's point about "ensure SQLAlchemy persists enum
     values" is a common trap. By default, SQLAlchemy enums might try to persist
     the Python member name. Using values_callable or native Enum support
     correctly ensures the string value matches the DB.

  4. Technical Minutiae (Defaults, Types, Constraints)
   * Agreement:

         uuid_generate_v4() and NOW() happen in Postgres. Using Python-side

         schema doesn't match the application behavior.

         indeed conflict with SQLAlchemy's Base.metadata. Renaming the attribute
         to metadata_ (or similar) while mapping it to column "metadata" is a
         standard and necessary workaround.

  5. Vector Support
   * Agreement: Explicitly mentioning Vector(1536) and the ivfflat index
     parameters ensures we don't just get a generic column but one that matches
     the specific pgvector configuration.

     Design Decisions

     1. Transaction Ownership

     - Repositories never call commit() or rollback()
     - Caller owns the transaction (service layer in P3+)
     - Use session.flush() to get DB-generated values
     - Use session.refresh(entity) after flush to load defaults

     2. BaseRepository Pattern

     class BaseRepository(Generic[T]):
         def __init__(self, session: AsyncSession, model: type[T]):
             self._session = session
             self._model = model

         async def get_by_id(self, id: UUID) -> T | None
         async def create(self, entity: T) -> T  # flush + refresh
         async def update(self, entity: T) -> T  # flush + refresh
         async def delete(self, entity: T) -> None  # session.delete

     3. Repository Methods (Schema-Anchored Only)

     WorkflowRepository:
     - get_by_workflow_id(workflow_id: str) — unique constraint
     - get_by_thread_id(thread_id: str) — unique constraint

     StepExecutionRepository:
     - get_by_composite(workflow_id: UUID, pass_type: PassType, step_name: StepName) — unique constraint

     CheckpointRepository (composite PK):

     from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

     class SolverCheckpointSaver(BaseCheckpointSaver[str]):
         """Custom checkpoint saver using SOLVER's existing schema.

         Adapts LangGraph checkpoint interface to our checkpoints/checkpoint_writes
         tables which lack checkpoint_ns, checkpoint_blobs, and use JSONB instead
         of BYTEA for writes.

         Note: checkpoint_ns is treated as empty string (no subgraph support).
         """

         def __init__(self, session_factory: async_sessionmaker[AsyncSession]):
             super().__init__()
             self._session_factory = session_factory

         @classmethod
         def from_conn_string(cls, conn_string: str) -> "SolverCheckpointSaver":
             """Create saver from connection string (Doc 3 API alignment).

             Creates internal async engine and session factory.
             """
             from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker
             engine = create_async_engine(conn_string)
             factory = async_sessionmaker(engine, expire_on_commit=False)
             return cls(factory)
